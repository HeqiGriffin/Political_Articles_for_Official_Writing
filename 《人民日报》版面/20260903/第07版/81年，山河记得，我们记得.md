# 81年，山河记得，我们记得

编者按：今年是中国人民抗日战争暨世界反法西斯战争胜利81周年。80多年前，中国人民同仇敌忾、奋起反抗，为国家生存而战，为民族复兴而战，为人类正义而战。所铸就的伟大抗战精神，在一代代人的接力中传承不息。

习近平总书记强调，要讲好抗战故事，把伟大抗战精神一代代传下去。“刘老庄连”官兵继承先辈遗志，精武强兵谋打赢；百团大战纪念馆讲好红色故事，赓续红色血脉；靖宇小学在将军故里，传承英雄精神。在抗战胜利纪念日来临之际，本报记者走进三地，在三处精神坐标里，记录一场场跨越时空的精神接力。

陆军第82集团军某旅“刘老庄连”——

过硬的战斗力，始终根植在红色血脉中

“1943年，为掩护淮海区党政机关和群众转移，全连82名指战员在刘老庄阻击千余敌军，战至最后一人……”近日，清华大学校园里，“刘老庄连”连长王宸一的一席话叩击着年轻学子的心扉。

讲台上的王宸一，曾在去年九三阅兵中，高擎“刘老庄连”战旗通过天安门广场，接受党和人民的检阅。回忆起连队先辈的英雄事迹与阅兵场上的震撼，他感慨：“生命不息，战斗不止！我们一定要传承好伟大抗战精神，赓续英雄血脉。”

八十余载岁月流转，英勇顽强的战斗作风，始终是连队的精神坐标。

去年深秋，漠北草原。一场实兵对抗演练进入胶着时刻，导调组突然设置特情：红方突击分队“刘老庄连”排长以上指挥员全部被定点“清除”。这超出预案的特情，就是要考一考连队班长骨干的实战水平。

官兵们没有慌乱和迟疑。一班班长、四班班长当即接替连长、指导员指挥，副班长悉数补位排长岗位，指挥链即刻重构。最终，官兵们将连旗稳稳插上蓝方固守的高地。

胜利归营途中，战车驶过一座铁塔，“从这里走向战场”7个鲜红大字，像一团火映照在官兵心头。

现代战争形态深刻演变，连队官兵清醒地认识到，传统固守阵地、集中冲锋的模式已难适应新战场。他们围绕隐蔽防护、小组协同、快速机动细化训练课目，加速锤炼“合成步兵”本领。

近期，在中原某驻训场，一场营战术演习中，面对蓝军无人机侦察、精准火力多轮压制，“刘老庄连”官兵分散布防、交替掩护、伺机反击，成功规避打击并控制核心目标，用实战检验了转型成效。

过硬的战斗力，始终根植在红色血脉中。在“刘老庄连”，每名战士入连都会领到一个专属战斗编号，从第83名开始，数字不断增长，精神却始终如一。

今年3月18日，是“刘老庄八十二烈士”殉国83周年纪念日，刘老庄籍新兵朱敬轩专程来到烈士墓前，与先烈进行了一场特殊的“隔空对话”：“长大后我才明白，英雄们把危险扛在肩上，是因为心中装着比生命更重要的东西——那就是家国，那就是人民。”

风过松林，誓言无声。从第83名到第6707名，这支英雄连队仍在冲锋。

山西阳泉百团大战纪念馆——

“一老一小”讲解队，两代人共传红色薪火

初秋时节，狮脑山松柏苍翠，山西阳泉百团大战纪念馆展厅内，一名佩戴红领巾的小讲解员站姿端正，为来自山西工程技术学院的参观者讲述百团大战的烽火往事。

“娘子关是山西和河北之间的重要关口，是正太铁路的咽喉地区，素有‘天下第九关’之称……”走到鏖战狮脑山展板前，她放缓语速，细细讲述革命先辈舍家卫国的英勇事迹。

为传承和弘扬伟大抗战精神，百团大战纪念馆与阳泉市上站小学建立长期共建机制，常态化开设红领巾讲解志愿岗位。百团大战纪念馆还搭建起“定期培训、轮值上岗、长效实践”的运行模式，将红色课堂搬进革命纪念馆，打造家门口“行走的思政课”。眼下，百团大战纪念馆还将与阳泉市老年大学达成合作，计划从朗诵班选出20名热爱演讲的学员，组建展厅“银发讲解员”队伍，推动“一老一小”讲解队发挥合力，两代人共传红色薪火。

“以前只在课堂上了解百团大战，成为讲解员后，我翻阅了纪念馆大量史料，才真正读懂了这场胜利的来之不易，更加珍惜今天的美好生活。”上站小学四年级二班“红领巾讲解员”梁语涵说。

如今，线上展厅同样热度不减。百团大战纪念馆打造VR（虚拟现实）云端展馆，整合文物三维模型与珍贵历史影像，游客扫码便能开启全景漫游，在线听讲解。馆内建成红色数字资源库，完成2500余份史料、2.12万页红色文献电子化归档，让革命文物、历史资料实现数字化保存，为后续史料研究夯实基础。

2025年至今，百团大战纪念馆接待海内外参观者超106万人次，为5400余批次近20万人次提供讲解服务。“我们将继续努力把百团大战厚重的历史转化为通俗易懂、打动人心的小故事，讲给更多的参观群众听，当好红色文化的宣讲者、传播者。”百团大战纪念馆馆长秦茹说。

河南确山县靖宇小学——

讲好英雄故事，是红色教育的必修课

幻灯片上，一边是低矮破旧的茅草校舍老照片，一边是窗明几净的现代化教室。鲜明的视觉对比，吸引在场学生的目光。9月2日，新学期开学第二天，一场名为“铭记历史  吾辈自强”的主题班会，在抗日英雄杨靖宇的母校——河南驻马店市确山县靖宇小学开展。

“同学们，如果让你选，你愿意在哪里上课？”五年级五班班主任李俊抛出问题，引发学生们思考。结合历史影像，李俊分享起校友杨靖宇的事迹。

“冰天雪地之中，杨靖宇将军弹尽粮绝，胃里只有树皮、草根和棉絮，依旧决不投降。”在杨靖宇将军事迹陈列馆，“小小讲解员”指着一张张图片、一件件文物，声情并茂地讲述着。

“讲好英雄故事，是学校红色教育的必修课。”确山县靖宇小学副校长董欣凤介绍，近些年，学校组建“靖宇小小宣讲团”，让英雄事迹代代传承。此外，还把英雄故事融入日常课堂，利用班会、安全教育时段，由教师分段讲述杨靖宇少年求学、投身革命、浴血抗敌的故事；校园广播站定期开设“靖宇故事汇”栏目，编排情景剧、诗歌朗诵、红色歌曲等，让英雄形象不仅停留在书本，更看得见、听得着。

“多年来，学校坚持常态化红色育人，探索出校本教材、阵地育人、实践活动三位一体的特色育人模式。”董欣凤说，学校编写了《靖宇魂》校本德育读本，并把将军雕像、校史陈列馆作为固定的德育实践阵地，新生入校第一课便是瞻仰雕像、学习将军事迹。

如今，英雄精神已转化为日常行动，越来越多的孩子争当红色宣讲员，常态化开展红色故事演讲、红色课本剧展演、祭扫英烈、红色研学等活动。“铭记抗战历史，我将传承抗日英雄杨靖宇的爱国精神，勤学奋进，将来成为对祖国、对社会有用的人才。”五年级学生赵子渝说。

寄语

我15岁时报名参军，亲眼见过山河破碎、百姓受难，也见过烈士们用血肉之躯筑起的坚固长城。可惜他们没有亲眼看见如今的盛世繁华，却用牺牲为我们铺就了光明坦途。

我由衷希望年轻一代永远铭记这段峥嵘岁月，铭记所有为国捐躯的烈士，不忘来路、不负先辈、不负家国。

——97岁八路军抗战老兵杨德山

我1943年参加抗日游击队，1944年底被组织分派到地方做后勤。那时候，前线的战士们在浴血拼杀，我们就攒军粮、补衣鞋，盼着能给前线多添一份力。

那些冒着枪林弹雨冲锋陷阵的战友们，好多连名字都没留下就牺牲了。现在日子过得热热闹闹的，可我常想起当年送粮时乡亲们眼里的期盼，想起战友们手里磨破的枪杆。如今咱们国家富强了，更得守好这来之不易的和平。

——102岁新四军抗战老兵孟超群

从太行抗日、淮海鏖战到渡江冲锋，数次负伤、6次无麻药清创的经历，让我深知，山河无恙从不是理所应当，和平盛世是先烈出生入死换来的。

我辈老兵已然老去，愿新时代年轻人常怀感恩之心，传承红色血脉，以奋进姿态守护和平、建设家园。

——99岁八路军抗战老兵靳虎堂

我是从炮火硝烟里走过来的，当年当兵，就是想救死扶伤、保家卫国。现在国家安定团结，老百姓吃穿不愁，这都是先烈拿性命换来的。

我不会讲啥大道理，就想劝后辈们，千万别忘了过去的苦。要懂得珍惜这来之不易的和平，好好过日子，守护好咱们的家国。

——100岁八路军抗战老兵景宝梅
