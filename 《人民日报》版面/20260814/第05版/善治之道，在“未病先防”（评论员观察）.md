# 善治之道，在“未病先防”（评论员观察）

在源头防风险，从苗头察隐患，于初期解难题，成本更小、效率更高

今年暑期，中医科里不少人是来“冬病夏治”的。“治未病”，中华传统医学的重要理念，习近平总书记多次用以指导基层工作。

基层是协调利益关系和疏导社会矛盾的“茬口”，也是群众感受治理温度的“窗口”。习近平总书记指出：“社会治理的最好办法，就是将矛盾消解于未然，将风险化解于无形。”在源头防风险，从苗头察隐患，于初期解难题，成本更小、效率更高。

治未病关键在“防”。中医讲究固本培元，减少病症发作。基层治理则要靠前服务，消解矛盾产生的土壤。

北京丰台北甲地社区，今年以来先后6次获评“无诉社区”。为啥居民没投诉，是“无欲无求”吗？当然不是。这个2023年才成立的社区有2600多户居民，最初邻里陌生、诉求分散、矛盾易发。社区主动开展网格巡查、建微信群、日常走访，将收集来的零散诉求，整理成治理议题，通过居民议事会逐一解决。如此，矛盾未等成诉便已化解。

以长效机制做足日常服务、前置疏导调解，才能避免小事拖成怨气、怨气酿成矛盾。这正是基层治理固本培元的核心要义。

立足“防”，就要善“察”。疾病发作前常有异常信号，问题出现前同样有迹可循。因此，要见微知著，精准捕捉苗头。

安徽合肥恒通社区有个“窗帘之约”：高龄、独居老人早7点半左右拉开窗帘、傍晚约6点合上窗帘。窗帘按时开合，证明老人安好；如若出现异常，志愿者立即上门查看，防止意外发生。

老人几天没下楼、楼道杂物越堆越高、邻里碰面刻意绕开……这些容易被忽略的细节，恰是风险预警的信号。发动和依靠群众的力量，把监测网络织得更密更细，有助于最大限度把风险防范在源头、消灭在萌芽。

小病不拖才不会演变成顽疾，小矛盾不搁置才不会发酵成积案。基层治理要做到“小病速愈”，重点在于快速响应、就地化解。

前段时间，山东济南舜承苑社区，租客熏香不慎引发火情，波及上下6户居民。原本极易演变成对簿公堂的复杂纠纷，却在街道“一窗受理、一站处置”的联动机制下快速解决。这背后，是“1小时到场、24小时启动处置”快速响应。

“小时不调，大时难了”，解决基层矛盾往往如此。北京的“接诉即办”机制、安徽桐城的“六尺巷工作法”、河南邓州的“四议两公开”工作制度……各地探索把“小事不出村，大事不出镇，矛盾不上交”落到实处，就是坚持处置在小的原则，不让小事拖大、大事拖炸。

从主观上看，从“事后灭火”转向“事前防火”也是思想之变、作风之变。有时候，阻碍行动的不是客观条件，而是“万一没事”的侥幸、怕麻烦缠身的逃避、只图眼下“清净”的短视。主动解决就是把姿态摆正，把责任扛牢，把群众的急难愁盼想在前、办在先。

在浙江工作期间，习近平同志把创新发展“枫桥经验”作为“平安浙江”建设的总抓手。党的十八大以来，习近平总书记从治国理政全局和推进社会治理能力现代化的战略高度，就坚持和发展新时代“枫桥经验”作出一系列重要指示，赋予其新的时代内涵。

“上医治未病，中医治欲病，下医治已病”，基层治理亦同此理。防范在先、发现在早、处置在小，正是坚持和发展新时代“枫桥经验”最生动的注脚，也是社会治理现代化最坚实的基石。
