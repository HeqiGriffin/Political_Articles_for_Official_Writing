# 年纪大了，也别让肌肉“悄悄退休”

【健·生活】

不少中老年人都有锻炼身体的好习惯，但日常运动常常局限于散步、快走、广场舞和太极拳等相对舒缓的有氧运动。这些运动固然能改善心肺功能、帮助控制体重，但若长期缺少肌肉力量训练，身体可能会面临一个容易被忽视的问题：肌肉量和肌力逐渐下降。

其实，对中老年人而言，肌肉功能是维持独立生活能力的重要基础。力量训练不是年轻人的专属，而是延缓功能衰退、降低跌倒风险、提升生活质量的重要方式。由此，我们呼吁——

守住行动能力，不能只靠“多走路”

肌肉是中老年人的“功能储备”。站起身、上楼梯、拎菜、抱孩子、走路不踉跄，背后都离不开下肢、核心肌群和上肢肌肉的共同参与。然而，随着年龄增长，肌力下降会影响中老年人的步速、平衡和反应能力，严重时还会增加跌倒和失能风险。因此，中老年人每天锻炼，不应只问“今天走了多少步”，还应多问一句：“今天是否进行了肌肉力量训练？”

世界卫生组织建议，成年人和老年人每周应至少进行2天涉及主要肌群的肌肉强化活动；对于老年人，还建议在每周身体活动中加入强调功能性平衡和力量训练的多成分身体活动，以帮助维持身体功能并降低跌倒风险。《中国人群身体活动指南（2021）》也提出，成年人每周至少应进行2天肌肉力量练习；65岁及以上老年人应结合自身情况，坚持平衡能力、灵活性和柔韧性练习。

具体应该怎么锻炼呢？力量训练，也常被称为抗阻训练，是指让肌肉在对抗外界阻力时主动收缩，从而提升肌肉力量、肌肉耐力和身体功能的训练方式。阻力可以来自哑铃、弹力带、器械，也可以来自自身体重，甚至可以来自家中的水瓶、书包和购物袋等。

中老年人坚持进行力量训练，好处有以下几点：

1.有助于守住行动能力。肌力不足和肌肉流失时，最先受到影响的往往是日常活动能力：起身费力、爬楼变慢、走路不稳、容易疲劳。规律的力量训练可以提高下肢支撑能力，让日常活动更轻松。

2.有助于降低跌倒风险。中老年人跌倒常常不是由单一原因造成的，肌力不足、平衡能力下降、反应变慢都可能参与其中。加强力量训练，配合平衡训练，有助于改善步态稳定性和身体控制能力。

3.有助于维护骨骼和关节健康。适度负荷会给骨骼、肌腱和韧带带来良性刺激，也有助于中老年人增强关节周围的肌肉支撑。但对于骨质疏松、膝髋关节不适或慢病人群，应先进行医学评估，再选择合适动作和强度。

4.有助于改善代谢健康。肌肉是人体重要的代谢组织。规律的力量训练可以提高肌肉对能量的利用能力，对中老年人体重管理、血糖控制和提升整体健康状态都有积极意义。

六组力量训练动作，居家可常做

对中老年人而言，进行力量训练的目标不是追求大重量，也不是挑战极限，而是逐步恢复和提升日常生活所需的力量、稳定性和平衡能力。例如，从椅子上坐下再站起，本质上就是一次下肢抗阻训练；扶着椅背做提踵运动，是在训练小腿和踝关节稳定；面对墙壁做俯卧撑，则是相对安全的上肢推类训练。

以下六组动作适合身体状况相对稳定、能够独立完成日常活动的中老年人，可以在居家时常做：

1.椅子坐站

训练重点：大腿前侧、臀部、核心稳定。

动作做法：坐在稳固椅子前1/3处，双脚与肩同宽，脚掌踩稳；身体微微前倾，慢慢站起，再控制速度坐回椅子。吸气下蹲3秒，呼气平稳站起。

训练安排：每组8~12次，做2~3组。每组之间休息1分钟。初学者可双手扶椅或扶桌辅助。

安全提示：膝盖与脚尖方向一致，不要突然“砸”回椅子；若膝痛明显，可减少幅度。

2.跪姿俯卧撑

训练重点：胸部、肩部、上臂后侧。

动作做法：双膝跪于软垫上，双手撑地，位置略宽于肩，身体从肩部到膝盖尽量保持一条直线。随后缓慢屈肘，使胸部向地面靠近，再用双手推地，将身体撑回起始位置。吸气下落，吐气推起。

训练安排：每组10~12次，做2~3组。跪姿无法完成者可改为站立对墙。每组之间休息1~2分钟。

安全提示：收腹，不塌腰，不耸肩；手腕或肩痛者可垫高双手。

3.坐姿弹力带划船

训练重点：背部、肩胛稳定、改善圆肩含胸。

动作做法：坐稳后将弹力带踩在脚底，双手握住两端，肘部贴近身体向后拉，感受肩胛骨向中间靠拢，再缓慢还原。吸气平稳后拉，吸气缓慢还原。

训练安排：每组10~15次，做2~3组。每组之间休息1分钟。弹力带阻力以动作可控为宜。

安全提示：不要用身体后仰代偿；不要弯腰、耸肩。

4.站姿提踵

训练重点：小腿、踝关节稳定、步行推进能力。

动作做法：双手叉腰，双脚略分开，缓慢抬起脚跟至最高点，停顿1~2秒后慢慢落下。过程中保持呼吸自然。

训练安排：每组15~20次，做2~3组。每组之间休息1分钟。进阶者可尝试单脚提踵。

安全提示：保持身体直立，不要左右晃动；避免膝盖过度“锁”死。如稳定性不足，可寻找扶手。

5.臀桥

训练重点：臀部、后侧链、腰髋稳定。

动作做法：仰卧屈膝，双脚踩地，收紧臀部将髋部抬起，使肩、髋、膝接近一条直线，抬至顶部维持2秒，再缓慢放下。吐气抬起，吸气缓慢下落3秒。

训练安排：每组8~12次，做2~3组。每组之间休息1分钟。

安全提示：不要用腰部硬顶；腰痛明显者需谨慎，可先做更小幅度。

6.轻负重行走

训练重点：握力、核心、姿势控制、全身协同。

动作做法：双手各拿一个装水水瓶或购物袋，挺胸收腹，目视前方，平稳步行。重量可根据自身力量水平自行调整。保持呼吸流畅，不要屏气。

训练安排：每次20~30米或30~60秒，做2~3轮，每轮休息1分钟。

安全提示：两侧重量尽量相近；不要含胸、耸肩。

每周怎么练？2天起步，循序渐进

中老年人进行力量训练，最重要的不是训练强度越大越好，而是练得科学、练得安全、坚持长期。以上力量训练可以和快走、骑车、游泳、太极拳等有氧和平衡练习搭配，形成更完整的运动方案。

对于中老年人，我们建议，刚开始练习这些力量训练动作时，不必每天练，也不必一次练很久。可以从每周2天开始，每次选择4~6个动作，每个动作2组，动作之间休息1~2分钟。待身体适应后，再逐渐增加到每周锻炼2~3天。

训练强度可以以“主观用力程度”来判断：若做完一组动作后感觉有点累，但还能再完成2~3次，通常比较合适。如果动作已经变形，或出现明显憋气、头晕、胸闷、关节疼痛等情况，应立即停止。

需要特别提醒的是，近期若出现不明原因胸痛、胸闷、心悸、晕厥或呼吸困难者；血压、血糖控制不稳定，或存在严重心脑血管疾病者；骨质疏松严重、近期骨折或关节肿痛明显者；近期做过手术，或有反复跌倒、明显步态不稳者；训练过程中出现疼痛加重、头晕、恶心、异常乏力等情况者，均应先咨询医生或专业人员是否适合进行力量训练。已有明确“无法运动”或“不建议运动”医嘱者，更不应自行开始以上力量训练。

肌肉功能的维护不是一时之功，而是贯穿中老年健康生活的长期任务。我们要明白，把力量训练纳入日常，不是为了追求高强度的运动表现，而是为了让身体更稳、更有力、更能应对日常生活。
