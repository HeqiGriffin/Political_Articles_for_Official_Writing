# “吵”出来的生产力

**原文链接：** [https://zqb.cyol.com/pc/content/202608/25/content_429841.html](https://zqb.cyol.com/pc/content/202608/25/content_429841.html)

中铁工程装备集团隧道设备制造有限公司（以下简称“中铁装备集团设备公司”）总装车间里，一场关于设备散热方案的争论已经持续了近一个小时。

车间组长别山磊经验丰富，坚持提议用“气水结合”的散热方式来减少用水量。一旁20岁出头的实习生小声说出了自己的不同想法，话没说完就被旁人打断：“你这种方法理论上可行，但现场根本撑不住。”

现场气氛一下绷紧了。有人面露难色，有人低头翻手册，只有别山磊开口说：“别急着说不行，先让他把话说完。”

于是，几个人又凑到一起，你一句我一句地继续讨论。最终，折中方案敲定——实习生提出的新思路被部分采纳，别师傅的经验补上了方案落地的细节。

这是近日发生的一幕，但其实这样的场景，经常在车间里上演。

“在我们这儿，敢说才敢干。”中铁装备集团设备公司团委书记赵溪茜说，年轻人敢不敢开口、敢不敢争辩，直接决定了他们能不能真正成长起来。

也正是这股“敢说”的劲头，让这家隧道专用设备制造企业的新质生产力，在一轮又一轮的“争吵”中，一点一点被“吵”了出来。

“吵”出来的师徒传承

别山磊今年不到40岁，但已经是车间里公认的“定海神针”，其带过的徒弟拿过的奖牌挂了满墙。

可在他的班组里，师徒之间从来不是单向的“我说你听”。面对专业上的分歧，别山磊不会直接压下去，而是把人都拢过来，各自摆依据。

“理不辩不明，遇到问题了，他说要走这边，我说要走那边，大家角度不同，谁能说谁一定对？”在别山磊看来，争吵不是坏事，而是解决问题的一种手段，“大家吵完了还是好兄弟，晚上该约打球就约打球，该吃饭就吃饭。”

刚开始，新来的年轻人是不太敢跟别山磊争的。车间里流传着一句话——“别师傅说第二，没人敢说第一。”他的业务能力超强，液压、电气、机械，没有他接不了的活儿。但慢慢大家发现，别师傅不怕人跟他争，就怕人不说话。

徒弟姚罗鹏评价：“师父这种包容谦逊的品质非常可贵，也深刻影响着我现在的做事风格。”

如今，姚罗鹏也变成了师父的角色，成了中铁装备集团设备公司调试车间的班组组长。一方面，他继承并发扬了车间里的这种文化，鼓励大家敢言敢干、积极沟通；另一方面，他始终坚持“不该吵的不能吵”。

有一天一个实习生因操作不当，把车间房板碰了个窟窿。姚罗鹏没有发火，先把人拉到一边确认没事，然后自己蹲下来看损坏程度。“实习生操作时旁边是要有师父带的，如果连师父都没发现问题，那怎么能‘吵’徒弟呢？”姚罗鹏说。

车间里的人都明白，正是因为有人愿意替年轻人扛第一下，年轻人才敢动手，敢开口，敢说出“我觉得不对”。

这种“吵不散，肯包容”的工作氛围，让年轻人既长出了本事，也养出了胆量。“敢跟师父争、敢提不同方案、敢为自己的想法负责，这样的年轻人，放到哪里都能独当一面。”赵溪茜说。

让彼此看清问题

00后青年饶实是中铁装备集团设备公司营销中心的一名员工。他的日常工作之一就是统计营销端的需求——客户要多少台设备、什么型号以及什么时间交货，并将数据反馈给生产部以便精准生产。

“一个设备客户要5台，生产端只能给3台，那就必须去协调。有时候因为零部件没到，有时候因为调试出现了预想之外的问题，交付延后了，这就是我们跟生产部最大的矛盾点。”饶实说。

一开始，两边一开会就“呛”起来，声音一次比一次高。

“你们营销就知道催、催、催，不知道我们这边已经连轴转了！”

“你们生产老说有困难，我们市场端这边的压力也很大啊。”

但吵着吵着，大家发现，吵架有时可能无法解决问题，但能让彼此看清问题。

饶实说：“吵完后，我能理解生产的难处，他们也能理解市场的压力。下次再遇到类似问题，效率就更高了。”

这种“以解决问题为导向”的争吵，逐渐形成了一套行之有效的协作模式。营销端提前把需求做得更精准，生产端把排产情况更透明地同步出来，两边每周对一次表，遇到紧急情况直接拉负责人到现场拍板。

面对营销中心巨大的交付压力，生产端调试班组的姚罗鹏创新提出了“调试端口前移，与总装生产并联”的设备调试模式，加快了设备的交付速度。

车间里还有一种“吵”，是自己跟自己较劲儿。设备散热方案确定后，别山磊带着一帮人闷头试了一个多星期，中间各种新问题层出不穷：方向不对、条件不够、高温不适……

别山磊说，那段时间内心有两个小人在“吵架”：“本我”在打退堂鼓“别折腾啦，你弄不成的”，但是“自我”却一直憋着一口气，“一定要把问题解决”。

最终，“自我”压倒“本我”，别山磊成功解决了车间设备的散热问题。

“公司的产品创新与效率提升，就是在一次次与他人、与自我的碰撞中实现的。”饶实说。

“敢说”的文化

“哪怕你是总经理，我也敢跟你争，因为你说的我不认同。”赵溪茜告诉中青报·中青网记者一个细节：公司有个博士，经常给总经理打电话到半夜，两个人就技术路线争得不可开交。“他们俩意见不一，其实总经理可以强压，但没用。他不认同的，就是要争论。”

领导不压，大家就敢说。这种“敢说”的文化，在公司里已经成为一种习惯：不是为了吵而吵，而是为了把事情做成。

有一次，一个年轻的技术人员在公司内部会议上直接对某个产品方案提出了反对意见，理由列了三条，每一条都有数据支撑。

在场的领导，没有人打断他。不久后，那个方案按照年轻人提出的方向做了调整。

“领导愿意听你说话，哪怕你说得不对，也会告诉你为什么不对。”赵溪茜说。

为了让“敢说”有更畅通的渠道，该公司团委专门设置了一个叫“解忧小栈”的平台。青年员工可以匿名投信，把工作中遇到的问题、困惑、不满写下来，投进意见箱。团委定期组织活动，随机从意见箱里抽出纸条，请在场的青年相互探讨。

“渠道畅通了，大家就愿意张嘴说话。”赵溪茜说，“哪怕问题暂时解决不了，我们也会给个答复，至少让青年知道，他的声音被听到了。”

这种畅通的反馈机制，让公司内部的“意见流动”变成了一种常态。技术上有分歧，当面沟通；管理上有建议，随时提报；跨部门协作有摩擦，拉个会吵一架就通了。

用争吵交换意见，用争辩推动创新。正是这种“敢言”的常态，让中铁装备集团设备公司在短短两年内实现了跨越式发展。2025年中铁装备集团设备公司营业额同比增长了60%以上，公司第二产业快速发展，顺利完成转型升级。
