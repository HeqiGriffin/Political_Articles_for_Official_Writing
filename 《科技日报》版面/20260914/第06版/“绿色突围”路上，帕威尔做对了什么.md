# “绿色突围”路上，帕威尔做对了什么

◎本报记者 金 凤

　　智能激光切割替代液氮切割，既省钱又提质；全自动焊接机器人兼顾物料抓取与熔焊作业，减少产品返工产生的能耗；六氟化硫“让位”于干燥空气，在保障电气安全的同时又消除了温室气体排放……走进江苏南瑞帕威尔电气有限公司（以下简称“帕威尔”），一系列生产设备和工艺，一改过去高能耗的面孔，以绿色低碳绘就高质量发展底色。

　　将智能化作为绿色化的技术底座，以绿色化作为智能化的价值体现，帕威尔累计投入超过5500万元，构建起全过程零碳体系，并入选工业和信息化部发布的2025年度绿色工厂名单。

　　近日，记者走进帕威尔，探寻其如何为产线植入“绿意”，又如何将节能减碳融入公司血脉。

　　光刀替代“氮刀”，月省2万元

　　“对于电力装备制造企业而言，节能减碳既必要又紧迫。”帕威尔副总工程师陆军告诉科技日报记者，“输配电成套设备的生产涉及金属加工、线束处理、装配测试等多个环节，能源消耗和物料使用密集，碳排放强度在装备制造领域处于中上水平，所以绿色化成为企业的核心竞争力。”

　　在帕威尔1号厂房，随着智能激光切割机的“光刀”划过一块块不锈钢板材，一件件开关柜的外壳用料初具雏形。

　　“以前，我们使用的是液氮切割机，储存及运输液氮过程存在挥发损耗，有间接碳排放，生产现场释放大量氮气，存在局部缺氧风险，而且钢材遇到液氮会冷脆，容易折弯、断裂，钢材切口还会有毛刺。后来换成激光切割机后，每月节约液氮采购经费约2万元，降低了生产过程的能源消耗和物料浪费。”陆军说。

　　此外，开关柜的装配涉及大量铜排加工和母线连接。通过引入数控铜排加工设备和自动化装配线，铜排一次成型合格率大幅提升，废料率和返工能耗也同步下降。

　　帕威尔生产智造部主任助理金星介绍，公司还建设了集重型机械加工控制、数字化装配、机器人焊接于一体的智能制造产线，实现了多工序自动化协同。

　　在厂房另一侧，全自动焊接机器人自动完成气箱的定位、拼装和焊接等全流程作业。机器人能焊接得更精准、稳固，可大大降低人工手工焊接不稳定导致的返工和修补，既减少了返工的能耗，也避免了返修过程中的材料消耗。

　　在厂房里，自动导向车也全面替代了燃油叉车，它们按需配送、优化路径，减少了无效搬运，使车间物流综合能耗显著下降。

　　陆军出具的一组数据显示，2025年，帕威尔在产值增长25%的情况下，总能耗反而下降了4.6%。

　　建设碳数据中台，追溯碳足迹

　　“绿色工厂的建设，离不开精准的碳核算体系。我们搭建了分工明确、数据互通的五大系统，既能从源头掌握物料流转情况，也能监测各个工序的能耗，记录碳足迹。”陆军解释，其中，企业资源计划系统（ERP）能管控整个公司的物料、订单进度和齐套率，避免中途缺料导致停工、返工；生产执行系统（MES）可记录整个生产过程的数据，包括用了什么物料、操作工是谁、由哪台机器加工、工序的实时能耗等，是记录碳足迹的必要手段；产品生命周期管理系统（PLM）能管理技术图纸和工艺文件，并匹配物料需求，支撑产品全生命周期低碳溯源；仓储管理系统（WMS）能快速定位物料位置，管控仓储物流碳数据；质量管理体系（QMS）则对质量数据进行分析，统计不合格品和废品损耗，精准核算无效碳排放。

　　“这些系统虽然不直接产生节能数据，但将碳排放核算从全厂估算，具化为产线、工序、单品的精细化动态核算，实现了主要元器件‘一物一码’的全链条可追溯。通过提升管理水平、减少废品和返工，间接降低了资源消耗。”陆军介绍。

　　依托这五大系统构建的数字化碳数据中台处于试运行阶段，帕威尔正持续完善其能耗异常告警、设备故障预警、负荷趋势预测、峰谷用电优化等功能模块。

　　待全面建成后，该中台将通过可视化大屏和AI分析，实时掌握各环节碳数据，发现异常后及时预警并触发调节指令。

　　厂房里机器轰鸣，厂房屋顶上也上演着光与电的“绿色协奏曲”。“我们在7号厂房楼顶铺设了光伏板，去年一季度已经投用，目前年发电量13万千瓦时。这些清洁电力通过公司内部配电网，直接输送至各车间和办公区，从源头减少了化石能源消耗。”陆军介绍，公司采取“光伏自发电+绿电购买”组合方式，目前厂区已实现100%绿电覆盖。

　　提高产品“含绿量”，打造低碳供应链

　　产线能耗降下来只是第一步，产品“含绿量”升上去则紧随其后。

　　“原有开关设备大量使用六氟化硫作为绝缘介质，六氟化硫的温室效应极强，1吨六氟化硫的温室效应相当于约2.4万吨二氧化碳的温室效应。现在我们在35千伏以下的环网柜、充气柜等多个产品的生产中，已经用干燥空气替代六氟化硫，实现零污染，现在公司正持续推进开关设备全电压等级‘去六氟化硫’。”陆军说，类似的尝试不是孤例，公司也在变压器制造中，用植物油替代矿物油，减少对化石能源的消耗，并将变压器原有的硅钢替换为非晶闭口立体卷铁心，使变压器的空载损耗明显降低、能效更高。

　　从产线到产品的“零碳”追求，需要供应链的协同发力。陆军介绍，在带动供应链绿色化方面，公司要求供应商采购低碳原辅料，并在生产制造过程中统筹考虑环境保护措施。

　　“在选择供应商时，我们优先选择有绿色工厂认证或绿色产品相关认证的供应商，并在技术协议和合同中对采购产品提出能效等级达到2级及以上、使用回收材料、减少有害物质使用等要求。”陆军说。

　　当节能减碳成为产业发展的共同趋势，帕威尔的绿色设备也让电力运行更具韧性、能源使用更加高效——环保气体开关设备助力配电侧的绿色替代，高能效变压器降低电网运行损耗，无功补偿装置全面提升电能质量与用电效率。通过为市场提供更节能、更环保的设备，帕威尔将减碳能力嵌入下游配电系统，让绿色理念在产品生产与应用中持续传递。通过设备升级、工艺优化、能源替代、数字管控、绿色产品研发的系统推进，帕威尔用零碳运营全体系管理，回答了时代关切：传统制造企业的绿色转型不是选择题，而是必答题，攀“新”逐“绿”不仅是“加分项”，更是企业重塑核心竞争力的基石。
