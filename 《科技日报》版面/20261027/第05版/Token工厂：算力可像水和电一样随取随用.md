# Token工厂：算力可像水和电一样随取随用

◎本报记者 魏依晨

　　[Token工厂通过集约化建设、共享化运营，有效降低智能算力的使用成本和技术门槛，让中小企业、创业团队等能够以较低成本接入大模型。]

　　江西省首个Token工厂项目日前正式落地南昌高新区。Token工厂项目由南昌高新招商集团有限公司与中国移动南昌分公司合作共建，是南昌高新区重点培育的人工智能赋能平台，标志着江西智能算力基础设施建设迈入新阶段。

　　作为面向人工智能大模型时代的新型算力基础设施，Token工厂以集约化、规模化方式，为大模型训练和推理提供高效、稳定、低成本的智能算力服务，让算力像水和电一样随取随用，全方位赋能千行百业数字化、智能化转型。

　　破解企业“用不起、用不好AI”痛点

　　“我们联合中国移动南昌分公司共建Token工厂，主要是破解区内企业‘用不起、用不好AI’的痛点，服务区内科创企业发展。”南昌高新招商集团有限公司董事、副总经理喻翊东说。据了解，Token工厂通过集约化建设、共享化运营，有效降低智能算力的使用成本和技术门槛，让中小企业、创业团队等能够以较低成本接入大模型，把更多精力投入到应用创新和产品研发上。

　　运营阶段，南昌高新招商集团有限公司将在深耕本地市场的基础上，同步向外拓展Token工厂业务，使工厂获取稳定经营收益，实现项目良性循环；健全工厂内部管理制度，强化成本管控，严格落实网络安全、数据安全相关要求，保障Token工厂长期可持续运转。

　　同时，Token工厂将成为吸引科创人才、创新项目和产业资源的“强磁场”，围绕算力服务衍生出一批新业态、新模式，加快形成大中小企业融通发展的创新生态。

　　“Token工厂正式首发亮相，是高新区主动布局人工智能新赛道的重要举措，也是补齐人工智能产业赋能短板、完善全域创新生态的关键抓手。”南昌高新区党工委委员、管委会副主任刘用强说。同时，南昌高新区将依托Token工厂算力底座，加快扩充智算资源规模，推进多行业垂类大模型本地化部署与适配优化，面向产业提供稳定可靠的Token供给服务。以该平台为牵引，南昌高新区将引进和培育一批大模型、智能应用、数据服务等上下游企业，打造人工智能产业集群；同步完善产业、创新、人才配套体系，持续健全全周期、全链条、全方位企业服务体系。

　　提供“算力+模型+应用”一体化服务

　　此次发布的Token工厂，将面向产业界提供封装标准化、服务高可用、价格有竞争力的Token产品，有效降低用户使用算力、大模型、平台的门槛。

　　中国移动南昌分公司党委书记、总经理陈佰华介绍，通过Token工厂将算力加工成Token对外提供服务，企业接入算力，就像用水用电一样，又快、又稳、又省。

　　Token工厂不只“卖算力”，更提供“算力+模型+应用”的一体化服务。中国移动模型服务平台（MoMA）的核心优势主要体现在丰富的算力供给、多元的模型服务、普惠的消费体验等方面。依托该平台，Token工厂聚合300余款主流大模型，支持制造、医疗、教育等细分行业模型接入。Token工厂采用“政策性牵引+市场化运营”相结合的模式，丰富用户选择；支持算力券、Token券补贴申报，让企业申报无忧、真正得到实惠；并不断引入、上架质量可靠、性价比高的Token，从而降低用户使用成本。

　　从“一域试点”走向“全省普惠”

　　当前，江西省正统筹推进算力网规划建设，深度融入全国一体化算力网。“Token工厂将与全省算力调度体系互联互通，实现资源互补、错峰使用，既避免重复建设，又提升整体算力利用效率。我们中心将在Token计量、结算、安全等关键环节先行探索，形成一套可操作的规范标准，为全省同类平台建设提供借鉴。”江西省计算机学会常务副理事长、江西省科技基础条件平台中心主任付康介绍。

　　目前，江西省算力联盟汇聚了江西省47家政企校研成员单位，将向Token工厂供给模型、数据和场景资源，把高校院所的人才、技术导入平台。同时，联盟将及时总结南昌高新区的好经验、好做法，向江西全省复制推广，推动Token工厂从“一域试点”走向“全省普惠”。
