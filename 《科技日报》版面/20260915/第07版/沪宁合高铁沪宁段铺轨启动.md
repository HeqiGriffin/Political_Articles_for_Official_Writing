# 沪宁合高铁沪宁段铺轨启动

　　科技日报讯 （记者李均 通讯员孙芹科 张军萌）记者9月11日获悉，在江苏省南通市通泰扬特大桥施工现场，随着首对500米长钢轨在铺轨机牵引下缓缓牵出、精准落位，由中铁一局集团有限公司承建的上海至南京至合肥高速铁路（以下简称“沪宁合高铁”）沪宁段铺轨施工日前正式启动，为后续全线铺轨贯通奠定坚实基础。

 　　作为国家“八纵八横”高速铁路网沿江通道的重要组成部分，沪宁合高铁是沪渝蓉沿江高铁东段线路。该线路长约554公里，设计时速350公里，全线设16座车站。针对铺轨工程量大、交叉作业频繁等特点，建设团队投用轨道工程智慧云平台、轨道工程运输管理智控平台，对作业车辆运行状态实施全天候、全轨迹监控，实现调度指挥与风险预警的一体化管控，确保施工安全有序。

 　　该项目建成后，对于打造“轨道上的长三角”，优化沿长江地区铁路网布局，服务长江经济带高质量发展，助力长三角一体化高质量发展等具有重要意义。
