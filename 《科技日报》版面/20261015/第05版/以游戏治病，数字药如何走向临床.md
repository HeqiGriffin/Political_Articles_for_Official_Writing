# 以游戏治病，数字药如何走向临床

【深瞳工作室出品】

采写：本报记者&nbsp;张&nbsp;晶

策划：刘&nbsp;恕&nbsp;&nbsp;李&nbsp;坤

　　沈至宣（化名）6岁，单眼弱视，左眼视力仅有0.3。坚持使用数字药《快乐视界星球·视觉训练软件》后，左眼视力有所提升。妈妈陪沈至宣到医院复查时说：“本来不抱希望，结果没想到用了20天，弱视治疗就突破了平台期！”

　　数字药，是数字疗法产品的“别称”，它依托软件以游戏的方式对患者行为进行干预，用来治疗疾病或减轻症状，目前被应用于神经康复与认知训练、儿童健康与发育、精神心理健康、慢病管理等领域。《快乐视界星球·视觉训练软件》这款数字药，就是针对儿童斜弱视开发的视觉训练系统。据中国医疗器械行业协会数字疗法专委会（简称“专委会”）资料，截至2025年12月底，我国已有150款数字药获批。

　　如何针对不同疾病研发更多数字药，并让它成为临床上的常规治疗选项，已成为业界关注的焦点。

　　突破传统治疗方法局限

　　数字疗法这个概念最早在2015年由美国心理学家卡梅伦·塞帕等人提出。2017年成立的国际数字疗法联盟将数字疗法定义为“基于临床证据的，以高质量软件驱动的，用于预防、管理或治疗疾病的治疗干预措施”。但是，不同国家医疗监管体系对这一新生事物的解释并不完全一致。

　　“我国业界常常把数字疗法产品冠以‘药’名，这种通俗的叫法更便于患者理解和接受。”上海交通大学附属第六人民医院南院药学部主任徐峰长期跟踪研究创新型数字药物。在他看来，数字药“非药”却“似药”。

　　数字药是大型人机交互的网络应用或干预型软件，类似游戏，但实际上是基于复杂算法和医学知识转换出来的医疗器械。

　　“数字药虽然不含任何传统药物的化学小分子或生物大分子，但其临床应用指导原则与传统药物相近，并用软件实现了药物的治疗作用。”徐峰告诉记者，表面上看，患者玩着游戏治了病，但起关键作用的是蕴藏其中的治疗原理。

　　从2018年开始，北京安定医院儿童精神医学首席专家郑毅就专注于数字疗法的研究。

　　郑毅告诉记者，数字药结合了循证医学和人工智能的特点，具有标准化、专业化、个性化和易操作的优势。在神经发育障碍、焦虑、抑郁等精神心理疾病的治疗中，这种优势更加突出。

　　以注意缺陷多动障碍（ADHD）为例。这是学龄儿童中患病率较高的神经发育障碍之一，临床上一直采取药物和非药物两种治疗方法，但两种治疗方式常常达不到预期的效果。

　　“患有ADHD的孩子，对药物的耐受度比较差，对药物的不良反应可能会更明显。同时，由于年龄小自制力差，他们很难严格遵医嘱做训练。”北京安定医院儿童精神科主任何凡解释。

　　游戏化形式通常更容易吸引儿童参与。何凡认为，对低龄患者而言，像游戏一样的数字药应用潜力很大。

　　针对ADHD的核心症状之一——注意力缺陷，郑毅率领团队已研发了6款数字药。这个数字药系列正是以游戏的方式对患者进行认知训练，采用即时奖励机制延长患者专注时间，促进患者脑功能提升。

　　何凡告诉记者，数字药还能为不同患者提供个性化治疗。游戏治疗具有一定的自适应性，患者可以选择适合自己的游戏模式，并适配能力提升难度，从而实现科学进阶。

　　此外，治疗成本低也是数字药的一大优势。

　　在抽动症的治疗中，综合行为干预是最具代表性的治疗方法。北京儿童医院精神科主任崔永华算了一笔账：按照传统治疗方法，孩子每星期要多次来医院接受治疗，每次治疗需要50多分钟。再加上路途奔波，治疗一次就得大半天，时间成本高，尤其是对上学的孩子。同时，抽动症治疗需要一对一训练，医疗人工成本也很高，而且国内多数医院无法提供相关医疗服务。

　　“在精神心理疾病治疗中，一些经典的传统治疗方法始终难以在国内大规模落地，成本高是主要原因之一。”崔永华说。

　　在这样的背景下，数字药开辟了另一种可能。

　　针对抽动症，崔永华团队研发的“数字化心理行为抽动监测方法及系统”，能让家长和孩子自主学习训练方法，不需要医疗人员全程指导。

　　“数字药是降低成本、提高治疗效果、提升医疗服务可及性的重要途径之一。”崔永华强调。

　　产业发展面临多重挑战

　　2020年，适用于慢病及慢性疼痛康复治疗的首款数字药“术康”在我国获批上市，国内数字疗法产业正式迈入合规发展的赛道。据《中国数字疗法产业白皮书》，2024年我国合规数字疗法市场突破30亿元，2020年—2024年复合增长率超60%，显著高于传统医疗器械行业增速。

　　中国电子信息产业发展研究院生物医药领域首席研究员、消费品所医药研究室主任曹慧莉认为，我国数字药产业已完成起步探索，进入快速成长期。

　　作为一种全新的药械形态，数字药在规模化落地过程中，从技术研发到商业化落地面临多重现实挑战。

　　数字药研发的底层逻辑是把已经经过临床验证的、成熟的治疗方案进行数字技术转化。所以，成功研发一款数字药取决于两点：一是归纳总结出适合数字化运行的治疗范式，二是找到恰当的技术转化方法。

　　据中国医疗器械行业协会数字疗法专委会调研资料，在数字药主要覆盖的12类疾病中，认知障碍占比最高，其次为视功能训练，多动症、慢性病等其他疾病所占比例都非常低。

　　专委会负责人刘重生认为，各类疾病不同的治疗范式是导致数字药发展不平衡的重要原因。他举例说，眼视光治疗的原理、技术和结果是“看得见”“摸得着”的。因此，将其转化为可循证医疗器械的技术路径比较清晰。但精神卫生领域疾病的治疗和疗效评估高度依赖患者的主观感受和行为表现，缺乏客观生物标记物。如何将复杂的医患互动、认知行为改变过程，科学地转化为可验证的软件算法并证明其临床价值，是当下行业正在攻坚的难点。

　　目前，精神卫生领域的数字药，无论是在研的还是已经批复的，绝大多数针对的是轻症。对中重度的治疗，还相对空白。

　　针对特定的疾病，即便形成了明确的治疗范式，还需要用数字技术把医学原理和治疗方法呈现出来，并确保治疗达到预期效果。这并不容易。

　　弱视是一种发育型疾病，发现后应尽早治疗，否则疗效会大打折扣。复旦大学附属眼耳鼻喉科医院主任医师刘睿介绍，治疗弱视最常见的是遮盖疗法，即通过遮盖视力较好的眼睛强制大脑使用弱视眼，从而刺激其视觉通路发育与恢复。

　　2020年，波克医疗科技（上海）有限公司组建了一支包含计算机软件、临床医学等领域专家的团队，研发用于治疗儿童弱视的数字药。

　　“开发一款好的产品，必须解决算法验证和数据质量门槛这两个技术问题。”波克医疗科技（上海）有限公司CEO陈航解释说，与遮盖疗法配合使用的训练图片，印刷参数不同，所起的作用也不同。把图片“平移”到电子设备上时，设备的屏幕亮度、分辨率、色彩表现等都会影响实际呈现效果，因此需要通过算法校准与参数优化，尽可能让电子图片符合视觉刺激的训练要求。在数据质量门槛方面，关键是确保同一软件在不同平台、设备上运行的一致性，这样才能使不同设备上运行的软件实现同样的治疗效果。

　　“《快乐视界星球·视觉训练软件》通过摄像头记录提取注视点、眨眼频率等基本眼动参数，揭开‘训练黑盒’，能让医生清晰了解训练过程，更精准地找到问题，制定更有效的治疗方案。”刘睿说。

　　与传统药物研发不同，数字药天生带着“医工共生”的基因。但在现实中，跨领域协作壁垒却严重制约了产业发展。

　　数字药通常属于软件类医疗器械，在临床验证中，需要患者高度配合，通过不断使用和交互反馈，来验证其疗效。让研发企业苦恼的是，数字药进入临床验证阶段，常常难以找到适配且能稳定合作的医院。签署协议开展临床验证的患者，常因要求严格、对试验过程担忧等原因而中止试验。

　　一边是企业难以找到合适的临床验证合作医院，另一边，医院推动的数字药项目也因卡在“找合作”的环节里空耗时间。

　　“研发高质量的数字药，医疗专家不可或缺。但是公立医院属于事业单位，不能从事经营活动，无法把研究成果直接转化为产品。”何凡告诉记者，团队研发的用于治疗注意缺陷的数字药已拿到计算机软件著作权，目前仍“待字闺中”。

　　业内人士指出，企业是否承接医院的数字药研发成果，并进行商业化推广，关键在于数字药临床应用场景是否精准、清晰，这决定着企业的投资决策。

　　创新研发的数字药转化为可应用的产品，还要迈过审批落地这道坎。

　　当前，我国将数字药纳入医疗器械监管体系管理。业内人士指出，传统医疗器械监管体系是基于传统药品和硬件器械搭建的，这套规则放到数字药身上，必然产生适配性错位。

　　数字药的边界很难确定。它是“游戏”，又具医疗属性，大部分产品集成了健康记录、训练治疗、科普宣教等多重功能。曹慧莉指出，目前国家药监局已建立专项分类界定规则，但部分跨场景复合产品的属性判定仍存在实操难点。

　　数字药需要依托临床反馈和真实世界数据，持续迭代算法、优化交互界面与干预流程。怎样才能平衡好动态创新与合规监管间的关系？曹慧莉告诉记者，按照我国医疗器械分级监管框架，影响产品安全与疗效的重大软件更新，需要开展评价并申报变更注册。界面优化等轻微更新，企业无需注册变更。

　　“在AI算法持续学习场景下，迭代边界判定实操难度高，企业预判更新属性、开展验证的合规成本也很高。如何在守住医疗安全底线的前提下合理释放软件迭代空间，仍是产业和监管部门共同探索的课题。”曹慧莉强调。

　　业内更为关注的是，在现有医疗管理体系下，怎样才能打通合规数字药入院落地的通道，使其更顺畅地融入临床常规治疗。

　　目前，绝大多数数字药缺少统一的医疗服务收费编码，尚未纳入国家医保目录。销售渠道以患者自费、企业C端订阅销售以及医疗机构小批量采购为主。多位业内人士在接受采访时指出，“落地链路打不通，数字药规模化应用的发展目标就很难实现。”

　　打通堵点畅通产业链条

　　数字药产业属于医药工业的前沿领域，中国电子信息产业发展研究院消费品所密切跟踪数字药发展状况。他们认为，当前，数字药正从“单品试点、小众应用”向“多品类覆盖、全链条成型、政策市场化双驱动”转型。推动产业从“规模扩张”迈向“质量提升”，需要多方协同发力。

　　业内人士指出，深度挖掘患者、临床需求，才能开发出一个好的产品，这不仅需要深度临床调研，也需要长期的技术积累。

　　“医生要学习掌握最前沿的治疗理念，加深对疾病的认识，不断探索形成新的诊疗方案和治疗方法。”崔永华认为，只有抓住疾病的本质，才能为数字药的研发开拓更广的空间。

　　“人工智能已经进入大模型时代，如果我们另辟蹊径，用人工智能技术‘克隆’出一位专家，那么智能体就能进行完全‘智慧化’的数字治疗。”刘重生提出，这是数字药未来发展的一个方向。面对新技术的快速发展，他建议，医疗机构除了临床医生，还应配备工程技术人员，培养科研型医生，这种组合能够不断刺激产生新的想法，也有利于推动治疗技术进行医工转化。

　　很多医疗机构都在探索数字疗法融入传统医疗体系的可能性，数字疗法企业也在摸索新的治疗靶点、新的临床应用场景。业内人士希望相关部门搭建数字药公共服务平台，打破信息壁垒，加强医院、企业等主体间的交流，促进“医工”合作；支持医疗机构、科研院所与企业共建临床数据库，依托大规模临床真实数据训练、优化算法模型，提升数字药产品对国内患者、临床场景的适配性与专业性。

　　中国互联网协会未成年人网络保护与发展工作委员会秘书长王斌在上海、山东等地调研时发现，科技公司进入数字药领域，能最大限度地调动各方面资源，推进数字药研发速度。“一方面企业能敏锐感知市场潜力，另一方面在走通研发设计、专利、医疗器械注册到产品的全链条方面，企业更有经验。”王斌认为，要让企业成为推动数字药研发的主体。

　　针对数字药对医疗器械管理带来的挑战，曹慧莉建议，细化分类监管规则，完善数字药专属分类目录，按功能和风险实施分级监管，厘清行业界定标准。加快完善数字药医疗服务收费编码体系，优先将慢病管理、康复干预、老年病防治等疗效明确、循证充分的合规数字药产品，纳入国家医保目录及地方惠民医疗清单。同时，构建“医保+商保+企业团检+个人自费”的多元化支付体系，鼓励商业保险机构、企事业单位将合规数字药服务纳入保险报销、员工体检保障范围。

　　数字技术与现代医学的深度融合，创造了一种全新的治疗模式。只有进入大规模临床应用，真正惠及每一位普通人的健康生活，数字药的产业化价值才能充分释放。
