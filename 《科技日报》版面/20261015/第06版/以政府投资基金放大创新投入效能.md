# 以政府投资基金放大创新投入效能

**原文链接：** [https://epaper.stdaily.com/statics/technology-site/index.html#/newsDetail?id=d0255faec18246bd950f89dd721f7a18](https://epaper.stdaily.com/statics/technology-site/index.html#/newsDetail?id=d0255faec18246bd950f89dd721f7a18)

---

◎蔡庆丰&nbsp;&nbsp;刘&nbsp;昊

　　7月8日，习近平总书记在国家科学技术奖励大会、两院院士大会、中国科协第十一次全国代表大会上提出，“财政经费在科技投入中具有风向标作用”，要“合理配置中央和地方财政资金，引导地方聚焦国家战略需求加大研发投入”，“要引导企业增加研发投入，调动更多社会力量支持科技创新”。政府投资基金作为财政资金撬动社会资本、协同金融资源推动产业创新的核心政策工具，其战略地位日益凸显。

　　三重角色推动区域产业创新

　　推动区域产业创新，既需要统筹地区产业布局规划，为创新活动奠定外部发展基础，也需要给微观主体直接注入创新动力，激发创新意愿与积极性。政府投资基金是地方政府通过财政资金介入资本市场的重要方式，兼具协调财政、金融与产业生态的三重角色。

　　政府投资基金是财政资金“放大器”，即，以财政信用的“种子”撬动金融资本的“活水”，为国家战略导向的科技创新提供充足资金保障。政府投资基金以财政出资为杠杆，通过基金层级架构吸引社会资本参与，实现资金规模的几何级扩张，使有限的财政资源产生数倍乃至十余倍的放大效应。

　　政府投资基金是金融资源的“组织者”，即，以政策导向引导金融资源配置方向，将社会资本精准导入基础研究、科技创新和关键技术攻关领域。金融体系天然偏好风险可控、回报周期较短的项目，政府投资基金以政策性目标校准金融资本投向，引导社会资本进入市场难以覆盖的薄弱环节，支撑颠覆性技术创新和关键核心技术攻关。

　　政府投资基金是创新生态“构建者”，即，以全周期的“资本链”贯通“创新链”与“产业链”，实现从实验室“最初一公里”到产业化“最后一公里”的全程赋能。解决科技创新成果在原始创新阶段资金的投入缺口问题，推动创新成果从源头培育向产业化递进。

　　这三重角色的聚合使政府投资基金既是财政、金融协同发力的重要载体，也是推动区域产业创新发展的中坚力量。

　　三大问题制约助推器作用发挥

　　政府投资基金要充分发挥创新“助推器”作用，关键是夯实其从“政策工具”走向“创新引擎”的制度基础。从当前投资实践来看，政府投资基金在引导创新要素流动、创新投资周期、关键创新环节投资等方面仍面临挑战，深层次的结构性困境与机制性障碍亟待破解。

　　一是“返投约束”阻碍创新要素自由流动。产业链协同创新内在地要求创新要素在产业链各环节、各区域之间自由流动与高效整合。然而，当前多数政府投资基金实行属地化管理，并设有返投比例要求。返投约束将创新要素配置锁定于行政边界内，直接阻断了跨区域创新链的衔接。尽管近年来相关部门明确要求“鼓励降低或取消返投比例”，但在实践中，大量地方投资基金仍未落实，返投约束致使创新资源难以依据产业链的技术关联和创新需求跨区域优化配置。近年来，各地投资基金不约而同地涌入半导体、新能源、人工智能等热门赛道。地方产业投资同质化布局，进而引发地区间产业发展的同质化竞争，并愈演愈烈。

　　二是“资金后移”导致创新资源支撑不足。政府投资基金的核心目标在于“重点投资产业关键环节”，以单点创新推动产业网络的创新协同。然而在投资实践中，各级政府投资基金普遍存在“不敢投”和“投不准”的问题，关键创新环节缺乏有效的资本要素支撑。初创期企业研发投入周期长、技术路线不确定性高，直接降低了政府投资基金早期介入的意愿。政府投资基金从而转向成熟期产业企业。“不敢投”直接导致初创环节陷入资金“缺血”状态。此外，由于缺乏对产业关键环节和核心技术瓶颈的专业性、系统性研判，政府投资基金的决策往往“随大流”，未能精准识别该投、能投的企业和产业，使有限的政策性资金未能有效锚定亟须支持的创新节点。

　　三是“考核机制”使得创新周期布局失序。《国务院办公厅关于促进政府投资基金高质量发展的指导意见》提出，要“发挥基金作为长期资本、耐心资本的跨周期和逆周期调节作用”，但在实际落地过程中，政府投资基金往往面临着“不敢等”与“不敢错”的双重困境。突破性创新项目从技术攻关到产业化突破往往需要10年乃至更久，大量地方投资基金存续期却仍被压缩在5至7年，“不敢等”长期创新成果落地导致政府投资基金将在产业创新急需长期资本支撑的节点排除在外。同时，政府投资基金承载着国有资产保值增值的刚性约束，在短期考核机制约束下，容错机制的缺位使得管理者倾向于以“无为”求“无过”，这种“不敢错”的投资倾向间接导致政策资金投资布局与创新长周期错配。

　　系统优化制度设计与运行机制

　　引导政府投资基金实现高效运转，切实助力产业高质量发展，亟须在制度设计与运行机制层面进行系统性优化，多措并举、协同联动，助推政府投资基金将资金势能转化为驱动产业转型升级的内生动力，为地区高质量发展提供坚实的制度保障。

　　第一，破除基金“属地化”壁垒，完善产业创新联动机制。一方面，加快促进“降低或不设返投比例”制度设计的落地，支持地理相邻、产业互补的地区联合设立跨区域产业创新基金联盟，以资本纽带将不同区域的科创资源与产业场景精准链接，充分释放产业创新活力。另一方面，将返投认定标准从“单一注册地”拓展至“产业合作、研发中心落地”等实质贡献维度，拓宽资本服务产业创新的空间边界，使投资行为真正服务于产业联动需求，推动跨区域创新生态的深度融合与良性互动。

　　第二，优化基金“投资端”结构，建立产业资本配置体系。一方面，把握政府投资基金“更加突出政府引导和政策性定位”的内在要求，创新制度设计，推动制度落地。支持中央与地方联合设立政策型产业投资引导母基金，以资本纽带将国家战略导向、关键核心技术攻关与长期资本供给精准对接。另一方面，将基金投资转向“原创技术突破、产学研协同转化、产业链创新能级跃升”等创新价值更高的领域，以及金融资本忽视的产业薄弱环节，使投资真正成为驱动产业创新发展的持久动力。

　　第三，改革基金“考核端”体系，匹配产业创新周期框架。一方面，加快促进“长周期考核与容错免责”等制度设计的落地，支持行业主管部门与专业投资机构联合设立产业创新周期评估联动平台，更好地发挥考核指挥棒作用，将创新不同阶段节点和资金存续期限、风险容忍度精准对接。另一方面，优化考核机制，改变“年度集中考评”的执行方式，建立“阶段性回溯评估与关键节点动态校准”相结合的过程管理模式，搭建起覆盖创新全生命周期的考核调适机制，使考核节奏真正跟上产业突破从量变到质变的演进节奏。

　　（作者蔡庆丰系厦门大学经济学院教授、“一带一路”研究院副院长，刘昊系福州大学经济与管理学院副研究员）
