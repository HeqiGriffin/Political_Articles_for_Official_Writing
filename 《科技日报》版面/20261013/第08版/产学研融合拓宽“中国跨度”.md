# 产学研融合拓宽“中国跨度”

## ——校企携手攻克多项重大技术难题

东南大学预应力团队专家与欧维姆相关负责人参观实验室缆索装置。受访者供图

◎本报记者 金 凤

　　星汉如潮奔涌，群峦屏息谛听。近日，贵州省平塘县大窝凼，被誉为“中国天眼”的五百米口径球面射电望远镜（FAST）迎来落成启用十周年。十年间，FAST时常牵动着东南大学土木工程学院教授郭正兴的目光。“FAST的建成来之不易，看着它取得的这些成绩，我们当年的付出值了。”郭正兴说。

　　2011年起，郭正兴带领团队一边进行FAST索网施工全过程计算分析，一边协助柳州欧维姆机械股份有限公司（以下简称“欧维姆”）共同解决悬空组网和高精度张拉等难题，最终如期完成索网制造和安装。今年，双方共同参与的五百米口径球面射电望远镜（FAST）项目荣获2025年度国家科学技术进步奖一等奖。

　　FAST施工现场的“并肩作战”，体现了东南大学土木工程预应力学科团队（以下简称“东南大学预应力团队”）与欧维姆40年来通过产学研融合结下的深厚情谊。

　　早在1986年，双方便探索携手打破海外技术垄断，蹚出预应力技术国产化创新之路。此后，他们建立协同攻关机制，推动多种预应力技术在土木工程结构中应用，在多项国家重大工程项目中攻坚克难，三次摘得国家科学技术进步奖。欧维姆也从一家地方小厂成长为“世界一流专业领军企业”，参与建设港珠澳大桥、深中通道、平陆运河跨运河桥梁、埃及鲁德·法拉杰轴心大桥等国内外约2000座桥梁，其中不乏国内首创和“世界之最”工程，多项参建工程获评“鲁班奖”“詹天佑奖”等奖项。

　　你中有我，我中有你，40年相依相伴，他们如何互相成就？

　　推进预应力技术国产化

　　在长江江苏段的“黄金水道”，主跨2300米的世界在建最大跨度桥梁——张靖皋长江大桥正“拔节生长”。这座大桥的主要承重构件是2根主缆，每根主缆拥有3万多根高强钢丝。

　　与众不同的是，主缆将拥有可“换装”的锚固体系。“它能确保卸载和更换每束索股时，主缆其余索股不松懈，桥梁结构受力不受影响。”东南大学教授刘钊介绍，锚固体系的研发、精细化分析及试验研究，由东南大学预应力团队和欧维姆共同承担。

　　上世纪80年代以来，我国桥梁、核电等重大工程建设呈现出大跨度、重荷载、高耐久和特种工程的特点，这对现代预应力技术提出了前所未有的挑战。

　　东南大学前身是南京工学院，有“建筑老八校”之称。该校土木工程系教授徐百川领衔的团队率先在国内开展高效预应力混凝土结构设计理论和工程应用研究。当时，团队已完成现代预应力混凝土结构计算理论和设计方法研究。

　　“但要将这些理论应用于土木工程领域，需要采用高强钢材制备的预应力筋。而锚固高强度预应力筋的锚具和张拉设备却被国外垄断。”东南大学教授孟少平回忆，那时，欧维姆的前身——柳州市建筑机械总厂是生产预应力锚具、张拉设备的民族企业，他们闻风而动，立足国家自主创新需求，开始寻求与东南大学等高校合作。

　　亟待验证的理论成果，遇上迫切的产业技术突破需求，一场“双向奔赴”水到渠成。1984年，东南大学联合多家机构，共同成立华东预应力混凝土技术开发中心，为我国预应力技术的快速普及和产业化奠定重要基础。两年后，欧维姆加入，成为该中心早期成员之一，双方由此开启产学研协同攻关。

　　“这种合作不是单方面的给予，而是双赢。”孟少平一语中的。

　　创建联合攻关协同机制

　　时代的浪潮托举东南大学与欧维姆在一项项重大工程中完成预应力技术的验证与应用，也助推这两个伙伴在深度合作中追“高”逐“新”。

　　2014年，东南大学与欧维姆的合作驶入“深水区”——东大-欧维姆预应力工程技术联合研究中心（以下简称“联合研究中心”）成立，欧维姆则在公司设立“国家预应力工程技术研究中心材料和装备研发部”，为双方持续开展技术交流与协同攻关搭建平台。

　　从那以后，时任欧维姆副总工程师的谢正元像一只“候鸟”，频繁穿梭于南京与柳州之间。有时他带来公司最新的技术需求，有时他会了解老师们正在做什么研究。而东南大学教授吴京与欧维姆的合作，就是源于联合研究中心的学术交流。

　　2022年，欧维姆承接全球单体容量最大的漂浮式风电平台“明阳天成号”的拉索供应和施工项目，但技术挑战极大。

　　“最初公司请专家来指导，但复杂的施工计算分析存在技术难题。在联合研究中心的一次交流中，吴京老师提出可以‘揭榜’，后来经过论证，大家决定联合攻关。”联合研究中心副主任、欧维姆副总工程师雷欢介绍，此后两年，吴京团队解析了每一根拉索的功能和作用，进行拉索系统的受力分析，提出张拉方案。依据该方案，欧维姆完成拉索安装与张拉。

　　如果说联合研究中心的“头脑风暴”创造合作机遇，那么体系化攻关则未雨绸缪。“公司会定期征集科研项目，至今已为联合研究中心提供1000万元科研经费。”谢正元表示，依托两大科研平台，东南大学和欧维姆“画出”螺旋式上升的技术创新曲线：欧维姆从一线工程中提炼技术痛点，东南大学负责理论分析、算法创新，随后，欧维姆完成样机试制、现场实测验证，推动技术在循环迭代中不断升级。

　　十年间，联合研究中心已资助20余项联合科研课题，涉及桥梁智能监测，纤维增强复合材料，核电、液化天然气特种预应力等前沿领域，累计产出专利108项，牵头、参与编制国标、行标、地标、团标合计13项，多项科研成果实现转化并应用于重大工程。

　　依托校企合作培养人才

　　从早期学习借鉴国际先进技术、推进关键产品国产化，到围绕重大工程开展自主创新、形成成套技术与装备体系，再到服务世界级工程、参与行业技术前沿探索，东南大学与欧维姆一路携手，持续演绎着“以教育培养人才、以人才驱动创新、以创新反哺教育”的生动实践。

　　人才培养的根基，早在徐百川那里就已埋下。上世纪60年代起，徐百川培养了一批预应力技术人才，他招收的第一个研究生吕志涛，于1997年当选中国工程院院士。徐百川的关门弟子孟少平，后来担任东南大学土木工程学院建工系主任、东南大学混凝土及预应力混凝土结构教育部重点实验室首任常务副主任。

　　而吴京于上世纪90年代跟随吕志涛攻读博士学位、经常旁听导师与欧维姆技术交流，如今已是国家预应力工程技术研究中心主任，并成为“广西产业创新战略支持专家”。

　　这种学术精神的传承，为后来的校企合作储备了关键人才，也让创新成果喷薄而出、创新活力竞相迸发。

　　吕志涛领衔的东南大学预应力团队与欧维姆等团队，系统构建并完善了我国自主知识产权的预应力技术体系，获2014年度国家科学技术进步奖一等奖。东南大学教授吴刚团队与欧维姆等多家单位，构建了针对混凝土结构病害“精准筛查与诊断”、“常见病”高效快速治、“疑难病”有效精准治的技术体系，应用到500余项重大工程中。相关项目获2019年度国家科学技术进步奖二等奖。

　　在常澄高速跨京杭运河大桥（今为常州圩墩大桥）建设中，刘钊、孟少平领衔双方团队，在国内率先开展矮塔斜拉桥第一代“双套筒灌浆鞍座锚固体系”足尺模型试验。历经20多年、七代技术迭代，该体系的力学性能不断提升，单根钢绞线可便捷更换。如今，该成套产品在国内矮塔斜拉桥市场占有率超85%。

　　创新的成果，最终又反哺教育。如今，东南大学土木工程学院的研究生们会不时去欧维姆做产品试制，开展多种试验；而学者参与欧维姆工程的经验，也被编入研究生教材中。

　　三代学术带头人、数代校企技术团队将预应力技术写进祖国的山川湖海，也正激励后来者为我国预应力技术走向世界开拓创新。
