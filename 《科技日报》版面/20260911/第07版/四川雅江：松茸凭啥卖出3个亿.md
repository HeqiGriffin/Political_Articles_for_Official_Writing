# 四川雅江：松茸凭啥卖出3个亿

【乡村振兴】

◎本报记者 刘 侠

　　“今早9点刚到的新鲜雅江松茸！”“给我来20斤！”……在海吉星·成都双流市场（成都农产品中心批发市场），野生菌一条街上人头攒动，空气中松茸香扑鼻而来。这个菌类交易集散地迎来一年中最热闹的时候。

　　四川是中国松茸三大核心产区之一。松茸生长在海拔2500—4000米的高山栎林或高山栎树混交林中，集中分布在四川甘孜州、阿坝州及凉山州部分区域。其中，甘孜州雅江县是“中国松茸之乡”，松茸核心保护区面积为2453公顷，松茸产量、产值在全国县级区域中位列首位。2025年，雅江县松茸交易总量为1121.5吨，产值3.2亿元。

　　雅江如何实现从“资源大县”向“产业强县”的转变，让小松茸撬动县域经济大发展？近日，科技日报记者前往雅江县采访，试图寻找答案。

　　做强标志性品牌

　　“松茸，新鲜松茸，来自原产地，当日采摘，当日发货，欢迎提前下单”……在位于雅江县八角楼乡的松茸交易中心，一朵朵当天从山上采挖的松茸被摆上摊位，空气中散发着松茸独特的木质清香，农户们的吆喝声不绝于耳。市场上人头攒动，在买卖双方的讨价还价声中，一包包松茸通过物流公司现场打包，发往四面八方。

　　雅江县农牧农村和科技局副局长朱磊告诉记者：“雅江县共7569平方公里，通过认证的松茸有机基地范围达2153平方公里。雅江县一天就有几种天气，十里不同天。今年上半年松茸菌丝体生长期间，本地降雨量比去年高出10%，非常适合松茸生长。”

　　白马降措一家是松茸采摘大户，最近每天清晨五六点，他们就打着手电进山采松茸。“要在凌晨5点至上午10点采挖，这个时间段的松茸品质最好。”白马降措说，过去松茸价格不高，如今产业化程度提高，外销渠道打开，松茸能卖上价了。在采摘季，他们一家人收入可达10万元。

　　近年来，雅江县始终把做强品牌作为核心，发布雅江松茸鲜品地方标准，聘请中国工程院院士李玉等40余名专家建立食用菌产业发展智库，举办中国松茸产业发展高峰会等系列活动。去年12月，“雅江松茸”获得“中国农业百强标志性品牌”称号，进一步打开国内市场。

　　当前，依托物联网、区块链、VR直播等数字技术，雅江县正构建“线上直播+线下体验”融合营销模式，入驻京东、淘宝、抖音等主流电商平台，全面拓宽全国销售渠道。今年以来，该县松茸线上交易占比30.2%，直播带货销售额超400万元。

　　赋予“数字身份证”

　　在雅江县米龙乡，村民们仔细挑选精品级新鲜松茸放入特制保鲜箱，带着泥土清香的松茸从这里开启全国之旅。

　　为锁住野生松茸的鲜味，雅江县搭建起松茸航空运输通道，引入顺丰、京东、邮政等头部物流企业，构建“冷链运输+航空直达+末端配送”全链条冷链体系，实现松茸48小时直达全国320个城市。

　　今年，松茸可通过两条新开通的雅江直达成都冷运专线运抵成都中转场，经绿色通道快速中转后，搭乘全货机发往全国各地。

　　同时，雅江建成全国首个“数字松茸”产业平台，运用物联网与区块链技术为每朵松茸赋予“数字身份证”：在采摘环节，为全县1000余户农牧民免费提供GPS定位智能背篓，对松茸采集环境信息、采集人员信息等进行数字化建档；在流通环节，通过“采摘云、服务云、流通云、治理云、监管云”五大模块，实现从采摘到销售全流程可溯。

　　“在未来3到5年，我们将引导企业加强对残次品松茸的利用，让产业链延伸至松茸功效成分提取、功能食品开发等领域，显著提升产品附加值；联动藏医药科研机构开发‘食用菌+中藏药’复合康养产品，开辟特色产业融合新赛道。”朱磊表示，下一步，雅江县将常态化开展本土农牧民技能实训，培育一批乡土技术能手、产业带头人、本土电商主播，构建“专家指导+本土骨干+全员参与”技术服务体系。
