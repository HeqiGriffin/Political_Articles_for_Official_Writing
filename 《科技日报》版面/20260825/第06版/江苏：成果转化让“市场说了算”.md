# 江苏：成果转化让“市场说了算”

**原文链接：** [https://epaper.stdaily.com/statics/technology-site/index.html#/newsDetail?id=9432e8ee0ddf4904932860777497d842](https://epaper.stdaily.com/statics/technology-site/index.html#/newsDetail?id=9432e8ee0ddf4904932860777497d842)

工程师在上海交通大学无锡光子芯片研究院光子芯片中试线刻蚀间工作。 新华社记者 胡智轩摄

◎本报记者 金 凤

　　江苏省科技重大专项、前沿技术研发计划中，企业牵头的项目分别不低于80%、65%；高校技术转移机构增设特设技术转移岗位，不受岗位总量和结构比例限制；支持高校院所以“技术入股+现金入股”方式，探索横向科研项目结余经费出资科技成果转化……在江苏省自8月21日起施行的《关于突出市场导向建设科技成果转化高地的实施意见》（以下简称《实施意见》）中，一系列举措释放“市场导向”的明确改革信号。以“市场导向”为“灵魂”，通过让企业站“C位”、提升技术转移服务效能、深化体制机制改革等举措，江苏正促进科技成果加速从实验室走向生产线。

　　“《实施意见》紧扣建立研用一体的科技成果高效转化应用新体系，坚持市场导向、企业主体，在项目组织、平台支撑、专业服务、激励机制等方面进行体系化重构，加快成果转化提质增效，牢牢把握新一轮科技革命和产业变革的主动权。”江苏省科技厅厅长徐光辉道出改革深意。

　　成果转化让“市场说了算”，江苏具体怎么干？

　　“80%”确保企业站“C位”

　　长期以来，高校院所大量创新成果“沉睡”在实验室里，而产业面临的技术难题又难以找到适配的解决方案。“在传统的科研范式中，高校出成果、企业搞应用，研发和应用脱节。我们希望强化企业的科技创新主体地位，把产业最迫切的技术痛点转化为科研最优先的课题。”江苏省科技厅区域创新与成果转化处处长吴彭一语中的。

　　在江苏，企业已经深度参与产业创新。目前，江苏87%的研发投入来自企业，89%的专利授权由企业创造，近80%的科技平台和高层次创新创业人才集聚在企业。这正是《实施意见》规定企业牵头项目“不低于80%、65%”的重要背景。

　　强劲的创新活力，使江苏有信心让企业在成果转化中站“C位”。《实施意见》提出，鼓励大型企业面向前沿和基础研究建设中央研究院；鼓励科技领军企业、链主企业发展CVC（公司风险投资）基金，并明确政府投资基金参股的CVC机构可参照适用让利政策，通过以“投”带“转”，让产业资本成为成果转化的加速器。

　　在丹阳慧创医疗设备有限公司董事长汪待发看来，企业牵头重大科技项目，可以有更大的技术路线决定权、经费使用自主权，能从产业需求中凝练技术方向，让成果更接地气，也能更早明确知识产权归属，将成果更快转化为产品，满足市场所需。

　　企业站“C位”，如何确保科研项目能解决行业共性关键技术难题，而非单一产品的商业迭代？江苏省科技厅高新处副处长张逍越告诉记者：“我们会邀请行业专家和高校院所专家一起，凝练产业发展需解决的科学问题，鼓励企业研发重大战略产品或具备市场应用前景的样品样机，并尽快投入生产，以满足市场需求、破解产业痛点。”

　　“真金白银”激励技术经理人

　　科技成果转化，需要一支懂技术、懂市场、懂投融资、懂谈判的专业化技术转移人才队伍和一批技术转移机构。这类人才和机构的缺失，是制约我国科技成果转化的一大短板。《实施意见》推出多项举措，建设技术经理人队伍，激励技术转移枢纽发展，并培养其服务能力。

　　比如，《实施意见》明确，高校技术转移机构增设特设技术转移岗位，不受岗位总量和结构比例限制；高校院所可在科技成果转化净收入中提取不低于2%的经费，用于奖励作出重要贡献的技术经理人。

　　我国高校事业单位人员到校外机构兼职取酬受到一定限制，高校技术经理人往往“想兼不敢兼、兼了不敢取酬”。如今，江苏突破“藩篱”，明确“符合规定的高校院所技术经理人可到市场化技术转移机构兼职取酬”。

　　江苏省教育厅科学技术与产业处处长韩叶祥解释：“此举鼓励高校技术经理人到市场化机构提高专业能力，有利于他们积累产业资源、了解资本对接渠道，也有利于完善‘高校挖掘成果+市场对接产业’的机制，同时还可拓展技术经理人的合法收入渠道，增强其职业吸引力。”

　　对促成重大成果转化的社会化技术转移机构，《实施意见》也明确，可按技术交易额的3%给予奖补。江苏省科技厅区域创新与成果转化处相关负责人说：“我们希望培育更多高水平的社会化技术转移机构，吸引更多的人才，促进科技成果早日落地。未来，江苏还将依托卓越工程师学院、江苏科技商学院，每年培养1000名技术经理人。”

　　松绑赋权破除“不愿转”

　　科技成果转化过程中，由于尽职免责和容错机制不健全，科研人员往往“不愿转”“不敢转”。《实施意见》破解成果定价难、评估周期长、不确定性大等痛点，推广“先用后转”“先研后付”“先研后股”等成果转化方式，为科研人员卸下负担。

　　“比如，《实施意见》鼓励高校院所通过协议明确未来行权条件的许可方式，支持企业成熟后再办理入股或转让。科研人员在创业初期无需办理复杂审批手续，只需签订许可协议即可使用成果创办企业，等到企业成熟后再行权，让估值更合理、国资更保值。”江苏省教育厅科学技术与产业处相关负责人说。

　　在部分高校院所中，横向结余经费使用渠道有限，难以直接用于成果转化；而科技成果若仅以技术出资作价入股又导致股权偏低、话语权不足。《实施意见》提出，支持高校院所以“技术入股+现金入股”方式，探索横向科研项目结余经费出资科技成果转化。

　　江苏省教育厅科学技术与产业处相关负责人介绍，未来，江苏还将明确横向项目结余经费认定、出资比例、审批程序、股权归属、收益分配等细节，用技术入股体现知识产权价值、现金入股提供企业流动资金，同时选择转化基础好、管理规范的高校先行试点，成熟后逐步推广。

　　“这些政策可以简化科研人员创业前期流程，助力我们抢抓转化机遇，同时也有助于盘活闲置经费，提升科研团队在成果转化中的话语权。”刚刚创业的南京大学教授梁世军说。

　　为成果转化“松绑”，《实施意见》也对国有资产、资金的管理释放宽容度。比如，江苏将创新国资管理，对成果作价入股形成的股权实行整体监测、分阶段考核，不简单以单个项目或单一季度盈亏作为考核依据，免除追责顾虑；对投资阶段较早、投资风险较大的创业投资类政府投资基金提高亏损容忍率，不简单以单个项目或单一年度盈亏作为考核依据。

　　“我们希望通过一系列改革措施，让成果转化有动力、有通路、有保障，真正做到科研的价值在产业中检验、创新的成色在市场里体现。”徐光辉说。

　　多位受访专家认为，《实施意见》的落地，既是江苏省在科技成果转化机制上的一次自我迭代，更在全国范围内投下一块“改革探路石”。其要义在于，将“市场导向”从抽象理念转化为可量化、可操作的具体标尺：以高占比的企业牵头项目回应市场需求，以技术转移枢纽建设提升转化实效，以国资管理与横向经费改革打消“不敢转”的顾虑。通过制度供给营造“让懂技术的人敢于探索、有成果的人敢于转化、投早期的人敢于投入”的创新生态，科技成果转化才能真正打通“最后一公里”。
